# 文档加密使用指南

## 概述

本项目支持对导出的PDF和Word文档进行密码保护,确保文档安全性。

## 支持的格式

- **PDF**: 支持128位RC4加密算法
- **Word (DOCX)**: 支持密码保护

## 功能特性

### PDF加密
- 用户密码(user_password): 打开文档所需的密码
- 所有者密码(owner_password): 修改文档权限所需的密码(可选)
- 加密算法: 使用PyPDF2默认的128位RC4加密

### Word加密
- 文档密码: 打开和编辑文档所需的密码

## 使用方法

### 1. API接口使用

在调用导出接口时,通过`encrypt`参数配置加密选项:

```python
import requests

# 导出加密的PDF文档
export_request = {
    "data": {
        "title": "机密报告",
        "content": "这是一份机密文档"
    },
    "template_ref": "tpl_123456",
    "output_format": "pdf",
    "encrypt": {
        "enabled": True,
        "password": "secret123"
    }
}

response = requests.post(
    "http://localhost:8000/api/v1/export",
    json=export_request
)

result = response.json()
print(f"加密文档已生成: {result['data']['file_url']}")
```

### 2. Python SDK使用

```python
from core.service.export_service import ExportService
from core.models.export import ExportRequest

# 创建导出服务
service = ExportService()

# 创建导出请求(带加密)
request = ExportRequest(
    data={
        "title": "机密报告",
        "content": "这是一份机密文档"
    },
    template_ref="tpl_123456",
    output_format="pdf",
    encrypt={
        "enabled": True,
        "password": "secret123",
        "owner_password": "owner456"  # PDF所有者密码(可选)
    }
)

# 执行导出
result = await service.export_document(request)
print(f"加密文档已生成: {result.file_path}")
```

### 3. 加密Word文档

## 配置参数说明

### encrypt对象参数

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| enabled | boolean | 是 | false | 是否启用加密 |
| password | string | 是(启用时) | - | 文档密码 |
| owner_password | string | 否 | None | PDF所有者密码(仅PDF支持) |

## 错误处理

### 常见错误

1. **密码为空**
```json
{
  "code": 40001,
  "msg": "启用加密时必须提供密码"
}
```

2. **加密失败**
```json
{
  "code": 50050,
  "msg": "文档加密失败: 详细错误信息"
}
```

## 安全建议

1. **密码强度**: 建议使用至少8位包含字母、数字和特殊字符的密码
2. **密码管理**: 妥善保管文档密码,丢失密码将无法打开文档
3. **传输安全**: 在生产环境中使用HTTPS传输加密配置
4. **密码存储**: 不要在日志或数据库中明文存储密码

## 性能影响

- PDF加密: 增加约10-20%的处理时间
- Word加密: 增加约5-15%的处理时间
- 加密操作采用异步执行,不会阻塞主流程

## FAQ

### Q: 加密后的PDF输入正确密码仍无法打开?
A: PyPDF2使用的RC4加密算法可能不被所有PDF阅读器支持。**推荐使用Adobe Acrobat Reader**打开加密的PDF,避免使用浏览器内置的PDF查看器。

### Q: 加密后的文档可以被解密吗?
A: 只有知道密码的用户才能打开加密文档,系统不提供解密功能。

### Q: 支持批量加密吗?
A: 是的,在批量导出时可以为每个文档配置不同的密码。

### Q: 加密是否影响文档质量?
A: 不影响,加密只是在文件层面添加密码保护,不改变文档内容和格式。

### Q: 忘记密码怎么办?
A: 加密文档一旦创建,如果忘记密码将无法恢复,请妥善保管密码。
